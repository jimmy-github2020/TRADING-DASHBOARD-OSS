# Phase T3 回測系統

最後更新時間：2026-06-24

## 目標

T3 的目標是讓 T2 建立的策略可以直接套用到歷史 OHLCV 資料，快速得到可比較的績效報告。初版聚焦在單策略、多標的、固定資金權重的回測流程，並保留後續替換成更完整回測引擎的邊界。

## 技術決策

原規劃提到 `vectorbt`。本階段先以 pandas / numpy 實作可替換的 `BacktestEngine`，原因如下：

- 目前專案 API container 使用 Python 3.12 與 NumPy 2.x。
- `vectorbt` 依賴 numba，常受 Python / NumPy 版本相容性限制。
- T3 初版核心需求是產生穩定的 API、資料表與前端報表；引擎可在後續固定相容版本後替換。

因此本次保留回測引擎邊界，讓未來改成 vectorbt 時不需要改動 `/backtest` 前端與 API contract。

## 已知限制

- 初版只支援多頭策略，不支援放空、槓桿、滑價與複雜部位管理。
- 多標的採等權資金切分。
- 事件型條件如 MACD 金叉若訊號只出現一天，持倉也會隨訊號消失而出場。
- `equity_curve` 對應有市場資料的交易日，不是完整日曆日。
- 手續費以進出場各扣一次估算。

## 驗收重點

- migration 可套用並建立 `backtest_results`。
- `POST /api/v1/backtest/run` 可回傳完整績效指標。
- 回測結果可寫入 DB。
- `GET /api/v1/backtest/list` 可回傳最近紀錄。
- `/backtest` 頁面可正常 build，並能載入策略、執行回測與顯示報表。
