# Phase T4 AI Market Brief 盤面摘要

最後更新時間：2026-06-25

## 目標

T4 將 AI 功能定位為「盤面摘要」，只做市場資料整理、技術面觀察、VIX 風險描述、板塊輪動與多因子排行現象說明，不輸出買賣建議。

固定免責聲明：

```text
⚠️ 本摘要由 AI 自動生成，僅供參考，不構成任何投資建議。
```

## 本次實作

### DB

新增 migration：

- `db/migrations/005_ai_market_briefs.sql`

新增資料表：

- `ai_market_briefs`

欄位：

- `id`
- `brief_text`
- `data_snapshot`
- `model`
- `tokens_used`
- `created_at`

### 後端

新增 `apps/api/ai_brief.py`：

- `MarketBriefService`
- watchlist 最近 5 個交易日摘要
- VIX 最新值與 5 日均值
- T2E 板塊輪動 top 5
- T2F 選股排行 top 3
- OpenAI chat completions 呼叫
- Redis 30 分鐘 context hash 快取
- OpenAI 失敗時回 503，不讓 API crash
- 自動補上免責聲明

新增 API：

- `POST /api/v1/ai/market-brief`
- `GET /api/v1/ai/market-brief/latest`
- `GET /api/v1/ai/market-brief/history`

### 前端

新增 `/ai-brief` 頁面：

- AI 盤面摘要標題與最後更新時間
- 產生摘要按鈕
- loading 打字動畫 skeleton
- 摘要逐字顯示
- 資料來源快照可收合
- 最近 5 筆歷史摘要
- 固定免責聲明提示
- `AI_BRIEF_ENABLED=false` 時顯示功能未啟用

全域導覽新增 AI 摘要入口。

## 環境變數

新增：

```text
OPENAI_API_KEY=sk-...
AI_BRIEF_ENABLED=true
AI_BRIEF_MODEL=gpt-4o-mini
```

## 技術決策

- 不新增 OpenAI SDK，改用 Python 標準函式庫 `urllib.request` 呼叫 OpenAI HTTP API，避免擴大 container dependency。
- 不從 API 內部 HTTP 呼叫自己的 `/analysis` endpoint，改直接重用 T2 analyzer class，降低服務內部繞路與錯誤面。
- 新增 history endpoint，因前端需要最近 5 筆摘要列表；`latest` 仍照原規格保留。

## 已知限制

- 無 `OPENAI_API_KEY` 時只能驗證 disabled / mock-like 流程，不能產生真實摘要。
- 目前只支援繁體中文摘要。
- 摘要品質依賴 DB 內 OHLCV、板塊 ETF 與排行資料的新鮮度。
- OpenAI model 預設 `gpt-4o-mini`，可用 `AI_BRIEF_MODEL` 調整。

## 驗收重點

- migration 005 可套用。
- `AI_BRIEF_ENABLED=false` 時 API 回 503，前端顯示功能未啟用。
- 有真實 `OPENAI_API_KEY` 時，`POST /api/v1/ai/market-brief` 可寫入 DB 並回傳 `brief_text`。
- `/ai-brief` 頁面可 build 並回 200。
- 回傳內容與頁面都包含免責聲明。
