## 決策原因

### Docker 命名

使用 `trading_dashboard_*` container、network 與 volume 名稱，避免與 HYMOVER 或其他本機專案衝突。

### Port 規劃

- Web: 3100
- API: 8011 external / 8001 internal
- Postgres: 5442
- Redis: 6380

這組 port 避開 HYMOVER 的 3000/5000。原規劃使用 API external port 8001，但本機已有既有 Docker/WSL 轉發占用，因此 T0 實作改為 8011，容器內仍使用 8001。

### DB Schema

`market_ohlcv` 在 T0 就加入 `provider` 與 primary key：

```text
(symbol, timeframe, provider, time)
```

這能避免 T1A 多資料來源寫入時產生重複資料或覆蓋問題。

### Worker

T0 worker 只保留 APScheduler heartbeat，不抓資料、不發通知。
