# 回測操作手冊

最後更新時間：2026-06-25

## 這個功能是做什麼

回測是把「你在 Strategies 建立的策略條件」套用到過去的歷史 K 線資料，模擬如果當時照這個條件進出場，最後績效會長什麼樣子。

它可以幫你回答：

- 這個策略過去有沒有賺錢？
- 最大回撤大不大？
- 勝率高不高？
- 交易次數是否太少或太頻繁？
- 同一策略套在不同標的，結果差異如何？

請注意：回測只代表歷史模擬，不代表未來一定有效。

## 進入頁面

1. 啟動服務：

```bash
docker compose up -d
```

2. 打開瀏覽器：

```text
http://localhost:3100/backtest
```

3. 或從右上角導覽列點選：

```text
Backtest
```

## 操作流程

### Step 1：先選策略

左側第一個欄位是「策略」。

請從下拉選單選一個策略，例如：

```text
T2 Smoke RSI Active
```

但要注意，`T2 Smoke RSI Active` 是開發驗收時用的 smoke test 策略，不一定適合正式分析。正式使用時，建議先到：

```text
Strategies
```

建立自己的策略，例如：

- RSI(14) < 30
- RSI(14) < 30 AND MACD 金叉
- MA5 上穿 MA20
- KD 黃金交叉

## Step 2：選擇標的

在「標的」區塊勾選要回測的商品或股票。

目前頁面提供的常用標的包含：

| 標的 | 說明 |
| --- | --- |
| `0050.TW` | 台灣50 |
| `006208.TW` | 富邦台50 |
| `2330.TW` | 台積電 |
| `2317.TW` | 鴻海 |
| `2882.TW` | 國泰金 |
| `^GSPC` | S&P 500 |
| `^NDX` | Nasdaq 100 |
| `^VIX` | VIX 恐慌指數 |
| `GC=F` | 黃金 |
| `CL=F` | WTI 原油 |

初學建議：

- 第一次只勾 1 個標的，例如 `2330.TW`
- 確認結果能看懂後，再一次勾多個標的

多標的回測時，系統會把初始資金平均分配到每個標的。

## Step 3：設定日期

設定：

- 開始日期
- 結束日期

建議初學設定：

```text
開始日期：最近 1 年前
結束日期：今天
```

注意：回測實際使用的是資料庫裡有 K 線資料的日期，不一定等於你輸入的完整日曆區間。

例如你輸入：

```text
2025-02-05 到 2026-07-11
```

但資料庫目前只有：

```text
2025-09-01 到 2026-06-23
```

結果就會以實際有資料的區間計算。

## Step 4：選時間框架

目前支援：

| 時間框架 | 說明 |
| --- | --- |
| `1d` | 日線，適合中短期策略回測 |
| `1h` | 小時線，適合較短線策略 |

初學建議先用：

```text
1d
```

因為日線資料比較穩定，也比較容易解讀。

## Step 5：設定初始資金與手續費

預設值：

```text
初始資金：100000
手續費率：0.001
```

`0.001` 代表 0.1%。

如果你只是先測策略，可以先保留預設值。

## Step 6：執行回測

確認以上設定後，點：

```text
執行回測
```

右側會出現績效報表與資產曲線。

## 結果怎麼看

### 1. 總報酬

```text
total_return_pct
```

代表整段回測期間的總績效。

例如：

```text
+110.81%
```

意思是初始資金如果是 `100000`，模擬期末約變成 `210810`。

### 2. 年化報酬

```text
annual_return_pct
```

把回測期間績效換算成年化數字。

注意：如果回測期間很短，年化報酬可能被放大，不要只看這個數字。

### 3. Sharpe Ratio

```text
sharpe_ratio
```

衡量「承擔波動後的報酬效率」。

簡單解讀：

| Sharpe | 粗略解讀 |
| --- | --- |
| `< 0` | 策略表現不佳 |
| `0 ~ 1` | 普通 |
| `1 ~ 2` | 不錯 |
| `> 2` | 歷史表現很好，但要小心是否過度擬合 |

### 4. 最大回撤

```text
max_drawdown_pct
```

代表資產曲線從高點跌到低點的最大跌幅。

例如：

```text
-12.65%
```

意思是回測期間曾經從高點下跌約 12.65%。

這是非常重要的風險指標。策略不是只看賺多少，也要看過程中可能跌多深。

### 5. 勝率

```text
win_rate
```

代表交易裡有多少比例是賺錢的。

注意：

- 勝率高不一定代表策略好
- 勝率低也不一定代表策略差
- 還要搭配 profit factor、最大回撤、交易次數一起看

### 6. 總交易次數

```text
total_trades
```

代表回測期間完成幾筆交易。

如果交易次數太少，例如只有 1 筆，結果參考價值會比較低。

你截圖裡的結果是：

```text
total_trades = 1
```

這代表那次回測幾乎只是單筆長持倉，不能直接判斷策略穩定性。

### 7. Profit Factor

```text
profit_factor
```

代表：

```text
總獲利 / 總虧損
```

簡單解讀：

| Profit Factor | 粗略解讀 |
| --- | --- |
| `< 1` | 虧損策略 |
| `1 ~ 1.5` | 普通 |
| `1.5 ~ 2` | 不錯 |
| `> 2` | 很好，但要檢查交易次數是否足夠 |

如果只有 1 筆交易，Profit Factor 可能會非常大，這時不要過度解讀。

## 資產曲線怎麼看

右側圖表是 equity curve，也就是資產曲線。

你可以看：

- 曲線是否穩定向上
- 中間有沒有大幅下跌
- 報酬是不是只集中在少數時間
- 是否長時間橫盤

圖中的紅色區域代表回撤壓力。

如果曲線看起來很漂亮，但交易次數很少，仍然要小心。

## 交易紀錄怎麼看

下方「交易紀錄」會顯示：

| 欄位 | 說明 |
| --- | --- |
| Symbol | 交易標的 |
| Entry | 進場日期 |
| Exit | 出場日期 |
| Days | 持倉天數 |
| Return | 單筆交易報酬 |

例如你截圖裡：

```text
2330.TW
Entry: 2025/09/05
Exit: 2026/06/23
Days: 291
Return: +110.81%
```

這表示策略在 2025/09/05 進場台積電，直到 2026/06/23 出場，這筆交易報酬約 +110.81%。

## 回測歷史

頁面底部是「回測歷史」。

用途：

- 查看最近 10 筆回測
- 點擊歷史紀錄載入舊結果
- 比較不同策略、標的、日期設定的差異

建議每次調整策略後，都重新跑一次回測，並觀察歷史紀錄中的差異。

## 建議的初學測試順序

### 第一次測試

```text
策略：T2 Smoke RSI Active
標的：2330.TW
日期：最近 1 年
時間框架：1d
初始資金：100000
手續費率：0.001
```

目的：確認頁面和資料都正常。

### 第二次測試

到 Strategies 建一個簡單策略：

```text
RSI(14) < 30
```

然後回到 Backtest：

```text
標的：2330.TW
時間框架：1d
```

觀察：

- 交易次數是否增加
- 最大回撤是否可接受
- 資產曲線是否穩定

### 第三次測試

同一策略，改測不同標的：

```text
0050.TW
006208.TW
^GSPC
GC=F
```

觀察策略是否只對單一標的有效。

## 常見問題

### 為什麼按執行回測後沒有交易？

可能原因：

- 策略條件太嚴格
- 日期區間太短
- 該標的資料不足
- 該策略在這段期間沒有觸發進場訊號

可以嘗試：

- 拉長日期區間
- 換成 `1d`
- 放寬策略條件
- 改測資料較完整的標的，例如 `2330.TW` 或 `^GSPC`

### 為什麼我輸入的日期和結果日期不一樣？

因為系統只會使用 DB 內實際存在的 K 線資料。

如果資料庫沒有某段期間的資料，回測會自動以可用資料計算。

### 為什麼交易次數只有 1 筆但報酬很高？

這通常代表策略很早進場後一路持有到結束。

這種結果不能直接代表策略穩定，因為樣本太少。

建議：

- 拉長回測期間
- 換不同標的
- 改策略條件
- 觀察至少 20 筆以上交易再評估

### 可以把回測結果當投資建議嗎？

不可以。

回測只是歷史模擬，不能保證未來績效。實際交易前仍需要考慮：

- 資料延遲
- 滑價
- 手續費與稅
- 流動性
- 風險控管
- 策略是否過度擬合

## 使用時的判斷順序

建議不要只看總報酬，請照這個順序看：

1. 交易次數是否足夠
2. 最大回撤是否能承受
3. 資產曲線是否穩定
4. Sharpe Ratio 是否合理
5. Profit Factor 是否合理
6. 同策略換不同標的是否仍有效
7. 同標的換不同時間區間是否仍有效

## 目前版本限制

T3 初版回測仍有以下限制：

- 只支援多頭策略
- 不支援放空
- 不支援槓桿
- 不支援滑價
- 不支援複雜部位管理
- 多標的會平均分配資金
- 事件型訊號可能造成短持倉或單筆長持倉

這些限制在看結果時都要一起考慮。

## 最簡短版操作口訣

```text
先建策略 → 選標的 → 選日期 → 用 1d → 按執行回測
先看交易次數 → 再看最大回撤 → 最後才看總報酬
```
